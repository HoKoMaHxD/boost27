# بوت النيترو والبوست وSnow — 1.9.1

هذه النسخة تستخدم خدمة **Discord Assets CDN/API (dcdn.dstn.to)** لجلب تواريخ شارات الحساب. لا تقرأ توكن حساب شخصي ولا تستخدمه؛ جميع الردود تصدر من البوت الرسمي.

## ترقية النسخة القديمة

1. استبدل ملفات المشروع بهذه النسخة، بما فيها package.json وpackage-lock.json.
2. احذف متغير **READER_TOKEN** من إعدادات الاستضافة وأوقف أي نسخة قديمة من القارئ.
3. احتفظ بمتغير **BOT_TOKEN** الخاص بالبوت الرسمي، وإعدادات السيرفر والروم إذا كنت تستخدمها.
4. ثبّت الحزم ثم شغّل البوت:

~~~sh
npm ci
npm start
~~~

تحتاج Node.js 22.12 أو أحدث. يمكن إدخال القيم من إعدادات الاستضافة مباشرة، أو نسخ .env.example إلى .env وتعبئته محليًا. غياب .env طبيعي عندما تكون القيم مضبوطة في الاستضافة.

## الأوامر

| الأمر | الاستخدام |
|---|---|
| -نيترو | مراحل النيترو لصاحب الأمر |
| -بوست | مراحل شارة بوست الحساب لصاحب الأمر؛ ليس عدد البوستات |
| -سنو | مدة العضوية في السيرفر ومراحل Snow |
| -ping | فحص استجابة البوت دون الاتصال بخدمة الشارات |
| -فحص [آيدي أو منشن] | تجربة مسار الشارات مباشرة بتوكن البوت وإرفاق تقرير تشخيصي |
| -مساعدة | تعليمات الاستخدام |

أضف آيدي مستخدم أو منشن لشخص واحد لعرض بياناته، مثل:

~~~text
-نيترو @User
-بوست 123456789012345678
-سنو @User
~~~

تعمل البادئة ! والأسماء الإنجليزية nitro وboost وsnow وhelp أيضًا. تعمل أوامر /نيترو و/بوست و/سنو مع خيار user اختياري، إضافة إلى /ping. يمكن استخدام منشن البوت ثم الأمر مثل @Bot نيترو.

## تجربة مسار الشارات المباشر

بعد تشغيل النسخة 1.9.1 اكتب داخل الديسكورد:

~~~text
-فحص 141947703742562304
~~~

يعمل -فحص وحده لحساب صاحب الأمر، ويقبل الآيدي أو المنشن و!فحص و-probe ومنشن البوت ثم فحص. هو أمر نصي؛ لا يسجل /فحص في هذه النسخة. عند تعطيل Message Content Intent استخدم منشن البوت ثم فحص.

يستخدم BOT_TOKEN الموجود أصلًا في إعدادات الاستضافة. يتحقق أولًا من اعتماد البوت، ثم يجرب GET /api/v9/users/USER_ID/badges وتفاصيل الشارتين 1 و12 إذا سمح مسار القائمة بالوصول. لا يتجاوز أربعة طلبات، ولا يعيد المحاولة تلقائيًا بعد الرفض أو مهلة الطلبات. يتوقف إذا لم يكن الاعتماد لبوت.

يرجع رسالة بأكواد HTTP وDiscord وملف badge-probe-USER_ID.json يحتوي الحقول المحددة للشارات فقط. يحتاج AttachFiles لإرفاق التقرير، ولا يحتاج EmbedLinks. لا يطبع توكن البوت أو البروفايل الكامل. تُحفظ نتيجة الفحص في الذاكرة ساعة، ويوجد فحص واحد نشط على مستوى العملية ومهلة دقيقة قبل فحص حساب جديد.

هذا مسار مرصود في عميل Discord وغير موثق رسميًا لوصول البوتات. نجاح HTTP 200 وحده لا يثبت وجود تاريخ النيترو أو البوست أو دقته. الأمر تشخيصي فقط؛ لا يستبدل مصدر -نيترو أو -بوست تلقائيًا. أرسل التقرير لمراجعة الحقول قبل اعتماد أي تغيير في مصدر البيانات.

للتشغيل من طرفية المشروع أيضًا:

~~~sh
node --env-file-if-exists=.env probe-badges.mjs 141947703742562304
~~~

## شكل النتائج وحساب المراحل

تعرض البطاقة الاسم والأفتار، Current Badge وNext Badge وTimeline وصورة المرحلة. تبقى الصور الأصلية والإيموجيات في هذه النسخة كما هي. عند استخدام تطبيق بوت آخر، يجب أن تكون الإيموجيات المخصصة الموجودة في src/badges.js متاحة له.

- النيترو: شارة أساسية قبل الشهر الأول، ثم مراحل 1 و3 و6 و12 و24 و36 و60 و72 شهرًا.
- البوست: أول شكل من بداية البوست، ثم مراحل 2 و3 و6 و9 و12 و15 و18 و24 شهرًا.
- سنو: Snow من البداية، وSnow Beast بعد شهرين، وSnow Special بعد 4 أشهر، وSnow Legend بعد 6 أشهر.

الحساب بالأشهر الميلادية مع معالجة نهاية الشهر والسنة الكبيسة. مواعيد شارات النيترو والبوست تقديرات مبنية على تاريخ الخدمة، وليست تحققًا من الشارة الحالية من Discord. لا تتعدل الرسائل القديمة تلقائيًا.

## مصدر النيترو والبوست وحدوده

يرسل البوت طلب HTTPS إلى:

~~~text
https://dcdn.dstn.to/profile/USER_ID
~~~

يرسل آيدي الحساب فقط، دون توكن البوت أو توكن حساب شخصي أو آيدي السيرفر. يستخدم premium_since للنيترو وpremium_guild_since لشارة بوست الحساب. لا يستخدم تاريخ بوست سيرفرك بدل تاريخ شارة الحساب، ولا يخمّن تاريخًا عند غياب البيانات.

الخدمة خارجية وغير رسمية. صاحبها لا يضمن مسار البروفايل أو لحظية البيانات، ولا توضح وثائقها طريقة القراءة الداخلية بما يكفي لضمان خلوها من حسابات مستخدمين مؤتمتة. إزالة حساب القارئ من هذا المشروع ليست ضمانًا لاستمرار الخدمة أو وصولها إلى كل حساب.

عندما لا تعرف الخدمة حسابًا، يظهر رد يوضح أن ذلك لا يعني عدم وجود الحساب أو عدم امتلاكه نيترو. وعندما تكون بياناته مخفية، يظهر رد مستقل. فشل الخدمة لا يؤثر على سنو أو ping.

## التخزين وتقليل الطلبات

- تحفظ تواريخ الحساب ووقت جلبها لمدة **24 ساعة**، وتستخدمها أوامر النيترو والبوست معًا حتى عبر سيرفرات مختلفة.
- يحفظ وقت الجلب في البطاقة باسم Data fetched، مع تنبيه أن بيانات الاشتراك قد تتأخر. هذا وقت استلام البوت للبيانات، وليس ضمانًا لوقت تحديث المصدر.
- تحفظ نتيجة الحساب غير المتاح أو المخفي أو التاريخ غير الصالح لمدة ساعة لتجنب إعادة طلبه باستمرار.
- تحفظ الذاكرة المؤقتة في data/profile-cache.json. لا تحفظ البروفايل الكامل أو الحسابات المرتبطة أو بيانات الدخول. يستمر الحفظ عبر إعادة تشغيل العملية ما دام المجلد باقياً؛ الاستضافة ذات القرص المؤقت قد تمسحه عند إعادة النشر.
- إذا تعذر حفظ الملف، يستمر التخزين في الذاكرة ويظهر تحذير في السجل.
- تجمع الطلبات المتزامنة لنفس الحساب في طلب واحد، مع فصل طلبات الحسابات الجديدة بخمس ثوانٍ على الأقل وطابور أقصاه ثلاثة طلبات.
- يحترم البوت مهلة 429 دون إعادة محاولات تلقائية، ويتوقف مؤقتًا عند تعطل الخدمة.
- لا توجد عملية فحص جماعي أو تحديث دوري للأعضاء؛ الطلبات الجديدة تبدأ عند استخدام الأمر فقط.
- لا يوجد رجوع إلى الحساب الشخصي أو واجهة Discord غير الرسمية إذا تعطل المصدر.

## أمر سنو

يقرأ سنو تاريخ العضوية الحالي عبر البوت الرسمي، ولا يحتاج خدمة DCDN. إذا خرج العضو ورجع، يبدأ الحساب من تاريخ رجوعه. لا يحسب تاريخ حصوله على رتبة الكلان ولا يوزع رتبًا.

## إعدادات البيئة

| المتغير | الاستخدام |
|---|---|
| BOT_TOKEN | توكن البوت الرسمي؛ مطلوب |
| GUILD_ID | اختياري؛ آيدي سيرفر واحد لتقييد الأوامر |
| CHANNEL_ID | اختياري؛ آيدي روم واحد لتقييد الأوامر |
| MESSAGE_CONTENT_INTENT | true افتراضيًا للأوامر النصية؛ false لأوامر / ومنشن البوت |

READER_TOKEN لم يعد مستخدمًا. لا تحتاج مفتاح API للخدمة في هذه النسخة.

امنح البوت صلاحيات View Channels وSend Messages وEmbed Links وAttach Files وRead Message History. للثريدات يحتاج Send Messages in Threads. أضف التطبيق بنطاقي bot وapplications.commands. للأوامر النصية فعّل Message Content Intent في Developer Portal؛ لا يحتاج هذا المشروع Server Members Intent أو Administrator.

## التحقق

~~~sh
npm test
~~~

تشمل الاختبارات الأوامر العربية والإنجليزية، المنشن والآيديات، سنو، صور المراحل، عدم إرسال اعتماد لخدمة الشارات، مدة التخزين وحفظه بعد إعادة التشغيل، البيانات المخفية وغير المتاحة، أخطاء الشبكة و429، تقييد الطابور وعرض وقت الجلب. اختبارات الشبكة في npm test تستخدم استجابات بديلة ولا تتصل بالخدمة.

أُجريت تجربة اتصال منفصلة بحساب المثال المنشور من صاحب الخدمة. لا تشمل تجربة نشر حي في سيرفرك أو ضمان وصول الخدمة لجميع أعضائك.
